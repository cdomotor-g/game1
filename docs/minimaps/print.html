Print the mini-map sheets

← the sheets Explorer

Print at 100% — no “fit to page”, no scaling, on A4 landscape. Each cell then comes off the paper at 16.7 mm across the flats, which is a world-map hex on the korvane-reach map at its four-sheet preset: a figure based for the campaign board stands in a mini-map cell without being re-based. Scale the sheet to fit some other paper and that stops being true, which is why this page offers no paper but the one the sheet is drawn for. For a file rather than paper, print and choose Save as PDF — the page size is already set, so the PDF is true size too.

The sheets bleed off all four edges. That is deliberate: they are drawn 303 × 216 mm and laid 3 mm out and up, so the colour runs past the paper rather than stopping short of it in a white line. A home printer keeps a few millimetres of margin it cannot print in; that margin eats bleed, and never the field.

One per terrain, printed once. A table needs whichever ground it is fighting or building on, which is rarely more than two sheets at a time. Both panels print on every sheet, so no sheet is ever the wrong sheet.
